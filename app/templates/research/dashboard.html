What this workspace contains

What is recorded. Research administration: each participant’s invitation, their consent status, which consent document version they decided on, and an append-only history of those decisions. Researchers also write experiment protocol versions — task wording, intended difficulty, recommended duration and intended completion criteria. A protocol is a task definition; no participant is linked to one.

What is not collected. There is no behavioural interaction data: no interaction events, no browser tracking, no experiment sessions or task sessions, no surveys, no frustration ratings, no observer annotations, no exports, no datasets, no model training, no inference and no adaptive intervention. Nothing about a student’s behaviour is collected, measured or inferred here.

Protocol activation. Activating a protocol version freezes its wording inside this catalogue and makes it the one active version for Version A collection. It starts no session and no collection, and it is not an ethics approval.

A participant shown as Active has read and accepted a specific version of the consent document. A participant shown as Withdrawn is no longer eligible for any future research session. What any future collection would cover, how long it would be kept and how it would be handled are matters for the consent document a participant accepted and for the approvals the centre obtains outside this platform — activating a document here is an administrative action, not an ethics approval.
